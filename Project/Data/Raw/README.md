# Raw data

The article texts are not committed. They were collected from newspaper archives
under institutional access and a personal subscription, and redistributing them
would breach the terms under which they were obtained.

Articles were retrieved by Boolean keyword query covering sustainable-building
coverage while excluding adjacent sustainability topics such as food, tourism,
fashion, and financial investment. Collection used three routes: institutional
archive access (FAZ, SZ), web scraping of the publisher's site (Luxemburger Wort),
and a personal subscription (Trierischer Volksfreund).

Corpus composition is documented in `Project/Docs/Corpus_Statistics.md`.
